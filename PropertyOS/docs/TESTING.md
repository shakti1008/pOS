# Testing checklist

## First load
- [ ] App opens without console errors
- [ ] Sign-up / sign-in works
- [ ] Workspace is created

## Core flows
- [ ] Add property → unit → tenant → lease
- [ ] Generate rent for current month
- [ ] Record a payment (UPI reference)
- [ ] View public receipt via shared link
- [ ] Create a repair request

## Advanced (after migration 011)
- [ ] Record a security deposit
- [ ] Create and pay a utility bill
- [ ] Create an agreement and sign it

## Offline & PWA
- [ ] Service worker registers
- [ ] App opens offline after first visit
- [ ] Install prompt appears on supported browsers

## Visual
- [ ] Appearance Studio changes theme correctly
- [ ] Brand logo appears in header and receipts
